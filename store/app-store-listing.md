# App Store listing — Ice Dash: Penguin Slide

Text for App Store Connect → the app → Distribution → the version's page,
one localization each (the language menu at the top right of the page). Limits:
name 30, subtitle 30, promotional text 170, keywords 100 (commas, no
spaces needed; words already in the name or subtitle count anyway, so they
are not repeated), description 4000. Written from `listing.md` (Google Play),
with Game Center for the board and iPhone/iPad for phone/tablet; checked by
script for length and for no word of Google. No emoji: App Store Connect
refused the description with them ("invalid characters"), Play takes them.

Names and subtitles, as saved on 3 Nov 2026 (App Information). English keeps
the owner's **Ice Dash: Penguin Slide** ("Ice Dash" alone is taken). App
Store Connect would not save that name for Romanian or Spanish ("already
being used"); the trouble turned out to be its page sending a localization
saved a moment before as if new, so after each language the page is loaded
again. The other languages carry their own translated name, which also
puts the search words in the name:
