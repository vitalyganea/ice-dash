# Google Play listing — Ice Dash

Text to paste into Play Console (Main store listing). Limits: app name 30
characters, short description 80, full description 4000.

English is the default. The other five languages go in through Grow users →
Store presence → Main store listing → Manage translations → Add your own
translations. Play takes release notes only in languages the listing has:
until 22 Oct 2026 it had English alone (the Romanian below had never been
added), and a release with ro-RO notes was refused.

## Written to be found (26 Oct 2026)

On 26 Oct 2026 the live listing still had the bare name "Ice Dash". It was
in English only, and its full description still said "four ways to play".
The texts below were rewritten for search, and they go in with 1.2.0, the
first build with ads:

- **Name.** Google Play weighs the name most, then the short description.
  Each name carries the words people type, not just the brand: penguin, snow,
  slide / пингвин, лёд / pinguin, gheață / pingüino, hielo / pinguim, gelo /
  Pinguin, Eis. **Not used:** on 27 Oct 2026 the owner kept the bare name
  "Ice Dash" in every language; the names below are only a proposal, and
  those words now live in the short and full descriptions.
- **Short description.** It says it is a penguin game, one tap, endless, on
  ice, and that it plays without internet. Players search for that last one
  in every language ("offline games", "игры без интернета", "jocuri fără
  internet", "juegos sin internet", "jogos sem internet", "Spiele offline").
- **Full description.** The first lines show before "more". They name the
  kind of game in the words players search for (penguin game, endless
  runner, one-tap, offline, arcade, casual), each used once or twice in
  sentences, never as a list. Play's rules forbid repeated or unrelated
  keywords, and the same goes for "best", "#1", "free" or emoji in the name.
- **Ads.** The texts no longer say "no ads, no data collected", which stops
  being true with 1.2.0. They say what is true: ads only when the player
  asks for one, no account needed, and the game itself plays offline.
- **Leaderboard.** Freeride mentions the Google Play Games leaderboard. If
  1.2.0 goes out without the board, drop that sentence.

### Publishing the privacy policy (free)
1. On GitHub: repository **ice-dash** → Settings → Pages.
2. Source: *Deploy from a branch*, Branch: `main`, folder: `/ (root)` → Save.
3. After a minute the page is at
   `https://vitalyganea.github.io/ice-dash/privacy.html` — paste that URL into Play Console.
